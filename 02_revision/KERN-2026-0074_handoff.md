## Part 1 — 논문과 리뷰 개요

**제목** Screening-level pin-cell neutronic sensitivity of a NuScale US600-like SMR fuel lattice to coolant-density perturbations from simplified primary-system degradation models

## Part 2 — 개정의 핵심 서사 (반드시 유지할 것)

원 논문은 **"SG 파울링이 −612 pcm으로 지배적"**을 주장했다. 개정본은 그것을 팔 수 없다.

원인은 입력 상수 세 개가 근거 없는 값이었기 때문이다.

| 상수 | 원고 | 확정값 | 배율 |
|---|---|---|---|
| R_f,max | 3×10⁻⁴ m²·K/W | 설계 1.76×10⁻⁵, EOL 8×10⁻⁵ | 1/17 |
| U₀ | 8,000 W/m²·K | 3,186 | 1/2.5 |
| 바이패스 | 0 → 8 % 파라메트릭 | 설계 7.3 %, 해석 8.5 % | 재정의 |

교정 후 결과는 한 자릿수 내려간다. **개정본이 팔아야 할 것은 세 가지다.**

1. FSAR 설계 조건에 정착시킨 결과 세 기구 모두 핀셀 수준에서 검출 한계 근처이며, SG 파울링만 그것을 넘는다. 이는 명확한 스크리닝 판정이다.
2. 검출 임계 조건을 제시할 수 있다. 어느 조건에서 감시 대상이 되는가.
3. 벌크 밀도로만 작용하는 세 기구가 전부 미미하다는 것은, 리뷰어가 지목한 **크루드(핀셀 내부에서 플럭스를 직접 교란)**가 다음 대상이라는 그의 주장을 실증한다.

초록과 결론은 "무엇이 큰가"에서 **"무엇이 검출 한계 이하이며 어느 조건에서 검출되는가"**로 완전히 뒤집어야 한다.

**부수 영향**: 세 번째 논문(assembly-level, `openmc-ismr-degradation-uncertainty`)이 이 코드 모듈을 무수정 재사용한다. 이번 개정이 끝나면 그쪽 절대 pcm 값도 재검토가 필요하다.

## Part 3 — 확정된 수치 (전부 실측, 스크립트 출력 기준)

### 3.1 공칭 상태

```
k0            = 1.407985
T_core_avg    = 285.83 degC      (FSAR 상수는 285.85, 루프 해는 285.828)
rho_nominal   = 0.749581 g/cm3
P             = 12.755 MPa
T_sat         = 329.38 degC
mdot_total    = 584.8 kg/s (루프 해) / 587.0 (FSAR)
T_cold        = 257.98 / T_hot = 310.07 / core_out = 313.68 degC
```

세 시나리오가 동일 기준상태에서 출발한다. 라이저만 `fsolve` 허용오차로 4×10⁻⁴ degC, 7×10⁻⁷ g/cm³ 차이가 남으며 반응도로 0.01 pcm이다.

### 3.2 표준편차 — 단위를 반드시 명시할 것

| 기준 | 값 |
|---|---|
| 배치통계 σ (keff) | 12.61 pcm |
| 라이저 21점 실측 sd (keff) | 10.54 pcm |
| 차분 √2σ (Δk) | 17.84 pcm |
| **차분 √2σ (반응도)** | **9.00 pcm** ← 개정본 판정 기준 |

Δk를 반응도로 바꾸려면 k₀² = 1.9824로 나눈다. **이 단위 혼동으로 두 번 오류가 났다.**

### 3.3 결과 (63런, 21점 × 3 시나리오)

| 시나리오 | 조건 | Δρ [pcm] | 유의성 |
|---|---|---|---|

| SG 파울링 | EOL R_f (η = 1) | −120.2 | 13.4σ |
| 바이패스 | FSAR 8.5 % (η = 0.156) | −17.1 | 1.9σ |
| 바이패스 | 15 % 외삽 (η = 1) | −60.7 | 6.7σ |
| 라이저 | 3 mm (η = 1) | +3.5 | 0.4σ |

설계 범위 안에서 두 기구가 검출 한계 언저리이고, 벗어나야 명확해진다.

### 3.4 밀도계수

```
dRho/dRho_coolant = 15,010 +/- 411 pcm/(g/cm3)   (42점, SG+bypass, 상대 2.7 %)
  Delta-k 로는 29,757 pcm/(g/cm3)
  잔차 5.31 pcm, 기대값 sigma/k0^2 = 6.36 pcm 과 일치
  절편이 공칭 밀도 0.74958 에서 반응도 0 을 5 pcm 이내로 지남
```

**라이저 21점은 회귀에서 제외한다.** 밀도가 3×10⁻⁵ % 이내로 고정이라 기울기에 정보를 주지 않으며, 넣으면 16,031로 6.8 % 끌어올린다. 정보를 주지 않는다는 사실 자체가 M9의 negative control 결과다.

시나리오별: SG 14,663 ± 599, 바이패스 15,342 ± 737.

### 3.5 라이저 = negative control 겸 σ 검증

밀도 변화 8×10⁻⁷ g/cm³(0.012 pcm)로 사실상 고정. 21점이 동일 계산 21회 반복에 해당한다.

- 실측 sd 10.54 pcm vs 보고 σ 12.61 pcm
- χ² = 14.2, df = 20, 95 % 구간 9.6–34.2 → **일치. 배치통계가 σ를 과소평가하지 않는다**
- η와 keff의 상관 r = +0.097, t = 0.43 → 추세 없음
- SG k₀는 라이저 분포의 z = +1.62, 백분위 90 % → 정상

**공통 시드는 상관을 만들지 못한다.** 라이저 21점이 시드 동일·입력 거의 동일인데도 σ만큼 흩어진다. 회귀 잔차 5.31이 작아 보인 것은 단위 환산일 뿐이다. 시드는 재현성 목적이며 모든 차분을 독립으로 취급한다.

### 3.6 엔트로피 (Minor 11)

4×4×1 메시, H_max = log₂16 = 4. **9점 확정** (세 시나리오 × η 0, 0.5, 1).

```
첫 배치        3.1024 – 3.1062
활성 평균      3.1031 – 3.1059
비활성-활성 차 -0.0049 ~ +0.0048  (부호 갈림 = 통계 요동)
비활성 sd 평균 0.0086  vs  활성 범위 평균 0.0953  (한 자릿수 차이)
```

첫 배치가 이미 수렴 상태다. 비활성 10이 충분함을 입증한다.

### 3.7 감속재 온도 (M5)

63점 전부 **558.98 – 562.91 K**. `c_H_in_H2O` 격자점 **550 K와 574 K 한 구간** 안. 24 K 폭에서 4 K만 움직이므로 보간 성격이 균일하다.

연료 900 K는 U235·O16 격자점(250, 294, 600, 900, 1200, 2500 K)에 정확히 존재하여 보간이 없다.

### 3.8 붕소 (M4) — 11점 완료, 확정

```
농도       1235 ppm 천연 붕소 (FSAR 평형주기 BOC, EOC <= 20 ppm)
k          1.407985 -> 1.299927   (Delta-k -10,806 pcm)
붕소 가치   Delta-k 기준 -8.75 pcm/ppm   <- FSAR -7.6 ~ -13.7 범위 안
           반응도 기준 -4.78 pcm/ppm    <- 범위 밖으로 보이나 단위 문제
```

무한격자가 k = 1.41 로 임계에서 멀어 같은 Δk 가 작은 Δρ 로 환산된다.
**FSAR 값은 k ≈ 1 노심 기준이므로 Δk 로 비교해야 한다.**

**표본 정합 확인 완료.** 무붕소 21점 중 짝이 되는 11행(인덱스 0,2,…,20)의
`T_avg_C` · `rho_g_cm3` · `mdot_kg_s` 가 붕소 11점과 완전히 일치한다.
열수력 해가 같으므로 두 계열의 차이는 붕소뿐이다.

밀도계수 비교 — **반응도 단위, 표본 일치 11점**:

```
무붕소 11점   14,536 +/-   792   ( 5.5 %)  잔차 6.28  기대 6.26
붕소   11점    6,210 +/-   988   (15.9 %)  잔차 9.66  기대 7.81
차이           8,327 +/- 1,267   (6.6 sigma)
감소 57.3 %,  배율 2.34 배
```

Δk 단위로는 28,770 → 10,489, 감소 63.5 %, 배율 2.74.
**배율은 단위마다 다르다.** 반응도 배율 = Δk 배율 × k₀붕소²/k₀무붕소² = ×0.8524.
σ 도 계열마다 다르다 — 무붕소 12.42 pcm(keff)→6.26 pcm(반응도),
붕소 13.20→7.81. k₀² 가 1.9824 대 1.6898 이므로. **섞지 말 것.**

**리뷰어 M4 가 옳다.** 무붕소 모델이 밀도 민감도를 반응도 기준 2.34배 과대평가한다.

**옛 6점 값은 폐기.** 이전 판의 "무붕소 15,838 / 붕소 5,779, 감소 63.5 %, 2.7배"는
6점 적합이고, 무붕소 6점 잔차가 0.82 pcm(기대 6.22)로 우연히 작았던 것이 원인이다.
11점에서 무붕소는 14,536 으로 내려가고 붕소는 6,210 으로 올라간다.

**63.5 % 의 우연에 주의.** 옛 6점 반응도 감소율도 63.5 %, 이번 11점 Δk 감소율도 63.5 %.
단위도 표본도 다른데 숫자가 같다. 하나를 다른 하나의 근거로 인용하면 안 된다.

**M6 과의 정합**: M6 이 쓰는 42점 통합 15,010 ± 411 과 M4 의 11점 무붕소 14,536 ± 792 는
0.53 σ 차이로 일관된다. 답변서에 이 한 줄이 들어가 있다.

**결정 사항**: 붕소를 대표 계수로 올리지 않는다. 대표값은 무붕소 15,010 ± 411 을 유지하고
붕소는 **반응도 기준 2.34배 보정**으로만 제시한다. 붕소 11점 불확도가 15.9 % 라
대표값으로 쓰면 M6 에서 내세운 2.7 % 가 무너지기 때문이다.
불확도를 낮추려면 홀수 인덱스 10점 추가(약 5 h)로 11.5 % 까지 가능하나,
현재 논지에는 불필요하다. 밀도 구간 확대는 불가 — R_f 상한 8e-5 는 실측 근거라
늘리면 Minor 9 와 충돌한다.

**부수 확인**: 감속재 온도 558.98–562.91 K(550/574 K 구간 안, M5 무수정 유효),
서브쿨링 39.6–43.6 K(전 구간 20 K 초과, M10 가드 미작동),

## Part 8 — 작업 규칙 (반복된 실수에서 도출)

이 프로젝트에서 다섯 번 오류가 났고 원인이 같았다. **부분 결과로 판단하고 나중에 확인**했다.

1. **결론 전에 필요한 값을 전부 계산한다.** 원 데이터 몇 줄이나 요약 통계 하나로 단정하지 않는다
2. **단위를 매번 명시한다.** keff / Δk / 반응도, pcm / 상대값. 이 혼동으로 두 번 틀렸다
3. **실측과 모델 예측을 섞지 않는다.** 어느 쪽인지 밝히고, 다르면 차이를 먼저 설명한다
4. **유리해 보이는 해석을 먼저 의심한다.** 회귀 잔차를 상관 이득으로 읽은 것이 그 경우였다
5. **답변서에 쓰기 전에 스크립트 출력으로 확인한다.** 암산이나 기억이 아니라

실제로 났던 오류: 라이저 6점만 보고 "논문의 결론이 흔들린다"고 판단 → 21점 sd는 정상. 227 pcm과 22.7 pcm 자릿수 오독. 공통 시드 상관 이득 주장 → 단위 환산이었음. FSAR Table 4.1-1을 "내부 모순"이라 판단 → 엔탈피로 계산하면 일치. 붕소 가치가 FSAR 범위 밖 → Δk로 보면 안에 있음.

## Part 9 — 답변서 작성 원칙

**M1의 구조를 다른 항목에도 적용한다.** 오류를 무조건 인정하고 감사 표시 → 정정표 → 그다음에야 증거 → 리뷰어 질문에 직접 답변. 방어부터 시작하면 나머지가 변명으로 읽힌다.

**리뷰어가 틀린 경우에도 "당신이 틀렸다"고 쓰지 않는다.** M10의 15–20 K 서브쿨링 제안이 그렇다. 공칭 서브쿨링이 15.70 K라 그 기준은 공칭 운전을 배제하는데, 원인은 원고가 코어 출구를 309.7 degC(실제로는 RCS 고온측)로 잘못 적었기 때문이다. **"저희가 잘못 적은 값 때문에 그렇게 보였고 그 오류도 함께 정정했다"**로 쓴다.

**SNR 표를 만들지 않는다.** 임계값 3의 근거를 물으면 또 다른 임의 선택이 된다. 계수와 불확도로 말하고, 유의성은 σ = 9.00 pcm 대비로 자연스럽게 읽히게 한다.

**약속형 문장 금지.** "has been added to the repository"는 실제로 커밋한 뒤에만 쓴다. 현재 `[TO RUN]`이 남은 항목: IF97 회귀 테스트 커밋, supplementary 정리, 엔트로피 궤적 그림, 문헌 비교값 확보.

**크루드는 이번 개정에서 하지 않는다.** 피복재 표면 퇴적층은 새 모델이고 AOA는 2D 무한격자로 다룰 수 없다. Section 5에 최우선 확장으로 명시하고, **세 기구가 전부 미미하다는 결과가 그의 주장을 뒷받침한다**는 논리로 연결한다.
